# ajuan-erp

## 特性

- 项目文档与版本记录已初始化，便于后续协作和发布管理。
- 仓库结构保持轻量，后续可以按业务模块逐步扩展。

## 安装

当前仓库尚未引入具体运行时或依赖管理工具。

```bash
git clone https://github.com/Clukay-Fun/ajuan-erp.git
cd ajuan-erp
```
