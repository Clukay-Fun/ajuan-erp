# 阿卷 ERP 视觉系统 —— 温暖的桌面 ERP

> 状态：v0.1 已采用（M6）。所有组件只用 `src/renderer/src/styles/tokens.css` 里的语义 token，不写裸色值。

## 方向

个人库存账本，Operate 模式：用户在完成任务，界面要"消失"在任务里。品牌感来自纸面温度、墨绿主色和精确的细节，而不是装饰。

- **纸面**：页面 `#F8F5EF`，侧栏 `#F2EEE7`，卡片 `#FFFDFC`，控件浅底 `#F4F0E9`，边框 `#E5DED4`（输入框 `#DED8CF`）。
- **墨色**：正文 `#20221F`，次级 `#6F716B`，辅助 `#999A94`。
- **品牌绿** `#2F7357`（hover `#286348`，浅底 `#E7F1EC`）：主按钮、当前导航项（浅绿底 + 绿字，不用白块）、入库、成功。
- **出库橙** `#C86F45`：出库、作废、危险操作、错误。
- **警告黄** `#C99B46`：预警、草稿、警告。
- **不加阴影**：卡片只用细边框；阴影只给抽屉 / 对话框 / Toast。
- 图表：入库 `--chart-in`（松绿）/ 出库 `--chart-out`（陶土橙），与徽标色区分开，避免柱状图过重。

深色是同一套温度的暖黑（`#1B1916` / `#242119`），不是蓝黑；主色提亮到 `#7CB995` 保证 4.5:1。默认跟随系统，设置页可强制；由 `<html data-theme>` 切换。

## 骨架尺寸

侧栏 224 · 页面左右内边距 32 · 标题 28/700 · 副标题 14 · 卡片圆角 12 · 按钮圆角 8 · 控件高度 40 · 导航项 42 · 大模块间距 24 · 卡片间距 16。

页面统一为：标题 + 操作 → 说明 → 筛选 / 提示 → 数据卡 → 主数据区（表格 / 图表）。

## 空状态

- **表格空状态**：表头保留，`<TableEmpty>` 放在 tbody 里，176px 高，一行标题一行说明。流水 / 单据 / 汇总都用这个。
- **大型空状态**：`<EmptyState>` 220px，仅用于首次初始化等页面本身没有结构的情况。
- 商品页期初库存未录入时是三行文字（标题 / 说明 / 当前状态），不是大空框。

## 按钮层级

Primary（绿实底）：入库 / 出库 / 保存 / 确认。Secondary（白底描边）：导入 / 导出 / 编辑 / 调整。Tertiary（文字）：查看汇总 / 全部 / 取消。同一视图里并列的绿按钮只有「入库 / 出库」这一对。

## 字体

系统中文无衬线（PingFang / 微软雅黑），不引入 web 字体。单号、路径用系统等宽。数字区域一律 `font-variant-numeric: tabular-nums`。标题 22px/600，卡片标题 14–15px/600，正文 14px，辅助 12–13px。

## 动效

只为状态服务，不做加载编排。曲线用 `--ease-out: cubic-bezier(0.23, 1, 0.32, 1)`，抽屉用 `--ease-drawer`。

| 场景 | 时长 | 方式 |
| --- | --- | --- |
| 按钮 / 导航按压 | 120ms | `scale(0.97)` |
| hover / 焦点环 | 120ms | 颜色、box-shadow 过渡 |
| 对话框 | 180ms | `scale(0.96) + opacity`，`@starting-style` 进场 |
| 抽屉 | 260ms | `translateX(24px)` 滑入 |
| Toast | 260ms | 自上方 8px 落入 |
| 骨架屏 | 1.4s 循环 | 仅加载态 |

`prefers-reduced-motion: reduce` 时全部时长归零。

## 状态

每个可交互组件：默认 / hover / focus-visible / active / disabled / loading。页面：骨架屏（非居中转圈）、空状态（说明下一步）、错误（说明问题与恢复）。危险操作二次确认并要求填写原因（作废）。

## 浏览器默认面

选区、光标、滚动条、焦点环、日期控件图标都随主题着色（`global.css`）。表单控件自带 box-shadow 焦点环，不叠加 outline。
