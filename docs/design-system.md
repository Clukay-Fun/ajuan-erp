# 阿卷 ERP 视觉系统 —— 同一套结构，两种气质

> 状态：v0.2 已采用。所有组件只用 `src/renderer/src/styles/tokens.css` 的语义 token，不写裸色值。

## 两个主题

交互层级、布局、操作习惯完全一致，只换视觉语言。**品牌色只负责交互**（主按钮、当前导航、链接、焦点环、图表主序列），正文永远是灰黑 / 白灰，状态色独立于品牌色。

### 浅色「Cold Moss」—— 经营模式

冷白灰 `#F6F7F8` → 白卡片 `#FFFFFF`（边框 `#E1E5E3`，阴影 `0 1px 3px rgba(20,30,25,.035)`）→ 文字 `#1D211F` / `#68706C` / `#99A09C` → 墨绿交互 `#2F7357`（hover `#286248`，pressed `#20513C`，浅底 `#E8F1EC`）。侧栏 `#F1F3F4`，当前项浅绿底 + 绿字。

### 深色「Violet Night」—— 工作台模式

墨黑 `#101114` → 卡片 `#191B20` → 输入框 / 浮层 `#202229` → hover `#252831`；不用阴影，靠明度分层。文字 `#F1F1F4` / `#B1B2BC` / `#777985`。紫罗兰交互：按钮 `#8E78EB`（hover `#A08CF4`，pressed `#7863D1`），链接 / 图标 `#9A82F6`，当前项 `#29243C` 底 + `#AA95FA` 字。

### 图表序列

入库 `--chart-in`、出库 `--chart-out`、成本 `--chart-cost`、毛利 `--chart-profit`（浅 `#5887C8` / 深 `#A38DF5`，深色里紫色自然参与图表）。

### 表格

`--table-header / --table-row / --table-hover / --table-divider / --table-selected`，浅色 `#F4F6F5 / #FFF / #F7F9F8 / #E6E9E7 / #EDF5F1`，深色 `#1D1F25 / #191B20 / #22252C / #292C34 / #29243C`。

## 骨架尺寸

侧栏 224 · 页面左右内边距 32 · 标题 28/700 · 副标题 14 · 卡片圆角 12 · 按钮圆角 8 · 控件高度 40 · 导航项 42 · 大模块间距 24 · 卡片间距 16。

页面统一为：标题 + 操作 → 说明 → 筛选 / 提示 → 数据卡 → 主数据区（表格 / 图表）。

## 空状态

- **表格空状态**：表头保留，`<TableEmpty>` 放在 tbody 里，176px 高，一行标题一行说明。流水 / 单据 / 汇总都用这个。
- **大型空状态**：`<EmptyState>` 220px，仅用于首次初始化等页面本身没有结构的情况。
- 商品页期初库存未录入时是三行文字（标题 / 说明 / 当前状态），不是大空框。

## 按钮层级

Primary（绿实底）：入库 / 出库 / 保存 / 确认。Secondary（白底描边）：导入 / 导出 / 编辑 / 调整。Tertiary（文字）：查看汇总 / 全部 / 取消。同一视图里并列的绿按钮只有「入库 / 出库」这一对。

## 字体

系统中文无衬线（PingFang / 微软雅黑），不引入 web 字体。单号、路径用系统等宽。数字区域一律 `font-variant-numeric: tabular-nums`。标题 22px/600，卡片标题 14–15px/600，正文 14px，辅助 12–13px。

## 动效

只为状态服务，不做加载编排。曲线用 `--ease-out: cubic-bezier(0.23, 1, 0.32, 1)`，抽屉用 `--ease-drawer`。

| 场景 | 进场 | 退场 |
| --- | --- | --- |
| 按钮 / 导航按压 | `scale(0.97)` 120ms | — |
| hover / 焦点环 | 颜色、box-shadow 120ms | — |
| 对话框 | `scale(0.96)+opacity` 180ms，`@starting-style` | 淡出 + `scale(0.98)` 160ms |
| 抽屉 | `translateX(24px)` 260ms，iOS 曲线 | 淡出 + 回移 16px 160ms |
| Toast | 自上 8px 落入 260ms | 淡出 + 上移 4px 160ms |
| 骨架屏 | 1.4s 线性循环 | — |

退场永远比进场快。位移幅度乘 `--motion`；`prefers-reduced-motion` 时 `--motion: 0`，只保留 opacity / 颜色过渡。键盘触发的页面切换不做动画。弹层用 `usePresence` 在 `open=false` 后多挂 160ms 播退场。

## 状态

每个可交互组件：默认 / hover / focus-visible / active / disabled / loading。页面：骨架屏（非居中转圈）、空状态（说明下一步）、错误（说明问题与恢复）。危险操作二次确认并要求填写原因（作废）。

## 浏览器默认面

选区、光标、滚动条、焦点环、日期控件图标都随主题着色（`global.css`）。表单控件自带 box-shadow 焦点环，不叠加 outline。
