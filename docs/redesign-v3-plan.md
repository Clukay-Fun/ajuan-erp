## 1. 现状检查

### 1.1 技术架构（不变）
- Electron 43 + React 19 + TypeScript；CSS Modules + 设计 token（`styles/tokens/*.css`、`styles/base.css`）；组件基于 Base UI 1.9。
- 数据库：node:sqlite，迁移在 `src/main/db/migrations/`；服务层在 `src/main/services/*.ts`；IPC 在 `src/main/ipc.ts`、`src/preload/index.ts`、`src/shared/ipc.ts`。
- 路由：`app/routes.ts` + `app/navigation.tsx`（自研 NavProvider，带 `seq`，切页会重新挂载页面）。
- 全局弹窗：`components/ui/Drawer` 的 DrawerHost（外观已是居中弹窗）+ `app/entityDrawers.tsx`；数据变更广播用 `lib/dataEvents.ts`。
- Photoshop：`src/main/psdIo.ts` + `services/psdExport.ts`。通过桥接目录用 JSON 任务文件和插件通信（`photoshop-plugin/ajuan-psd`：Mac 用 UXP，Windows 用 CEP）。生成时把模板复制成 `template.psd` 放进任务目录，**从不改动源 PSD**。
- 测试：Vitest（107 个单测）；E2E 用 `tests/e2e/*.e2e.cjs`，共 a11y、backup、csv、flow、smoke 五个场景；截图脚本为 `scripts/screenshot-after.ts`。

## 2. 原型 / 说明与现有规则的差异（需要先确认，不自行改动）

| # | 差异 | 现状 / 规则 | 建议 |
| --- | --- | --- | --- |
| C1 | 深色主题配色：说明写「墨绿强调色」 | 你之前定的是：深色保留紫罗兰，数字 / 标题 / 商品名用品牌色（已写入记忆） | 浅色用墨绿；深色默认仍用紫罗兰。V3 设置页的「强调色」允许用户自选，墨绿也是选项之一 |

| C4 | 去掉收起侧栏 | 上一轮阶段 3 做了双态侧栏（⌘\ 收起） | 按说明删除收起功能和快捷键，侧栏固定约 170px |
| C5 | 商品改成卡片，不显示可售天数 | 现在是表格，预警值可双击就地编辑，异常行有红 / 琥珀色条 | 卡片里不放就地编辑，改在详情弹窗的「编辑」里改；库存异常用卡片上的小徽标提示（说明没有禁止，属于状态展示）。**需确认要不要徽标** |

| C9 | 模板重命名 | 没有接口 | 新增写接口 `psd.renameTemplate`，只改 `psd_templates.name`，不改表结构 |
| C10 | 「生成任务」在图层映射不合法时禁用 | ERP 读不到 PSD 图层，插件只在执行任务时报错 | 只校验图层名的格式（非空、无非法字符、同一模板内不重复）。PSD 里是否真有这个图层，以任务回执为准，失败时把插件报的原因显示出来。**读取图层需要扩展桥接协议，说明禁止改协议，所以不做** |
| C11 | 删除被位置引用的素材要提示 | 位置和素材的绑定不入库 | 删除前检查两处：当前生产页的选择，以及排队中 / 生成中的任务。被引用时提示，并清掉界面上的选择。不新增持久化字段 |

## 3. 逐页实施方案

图例：**[前端]** 只改界面；**[接口]** 需要新增或扩展 IPC；**[插件]** 涉及 Photoshop 插件（本计划不改插件）。

### 3.0 全局框架
- **[前端]** `components/Shell.tsx`：侧栏固定约 170px，去掉收起按钮、⌘\ 快捷键和收起状态的存储；保留顶部「新建出库单」分体按钮；选中项为浅绿底加左侧强调条（沿用现有样式）。
- **[前端]** 设置模式：`route === 'settings'` 时，Shell 渲染 `SettingsNav`（约 230px：「← 返回应用」+ 五个分类），代替主导航。`navigation.tsx` 记录 `previousBusinessRoute`，「返回应用」时切回这个页面。
- **[前端] 页面常驻（C13，完全不丢状态）：**
  - 页面容器改为：访问过的业务页（概览、商品、单据、定制）保持挂载，非当前页用 `hidden` 隐藏；设置页同样常驻，记住上次的分类。筛选、滚动位置、展开状态、生产页的选图和标题输入、未提交的就地编辑都保留。
  - 去掉 `seq` 触发的重新挂载。原来「再次点同一页就刷新」的效果，改为「页面被激活时刷新数据」：新增 `usePageActive()` 钩子，页面变为当前页时触发 `load()`，数据有变化时通过现有的 `useDataChanged` 刷新。刷新时保留筛选和滚动位置。
  - 隐藏页要停掉副作用：全局键盘监听（单据页 ⌘F 等）只在当前页生效；定制页 1.5 秒的看板轮询在页面隐藏时暂停，激活时立即补拉一次；任务完成的 Toast 仍然弹出（与当前在哪一页无关）。
  - 导航参数（如概览跳到「单据 · 草稿」）在页面已挂载时作为「外部指令」应用：只更新对应的筛选，不重置其他状态。
  - 全局弹窗（DrawerHost）的行为不变：切页前若有未保存的弹窗，仍先确认。进入设置时不强制关闭弹窗以外的页面状态。
  - 滚动容器：每个页面用自己的滚动区，切走再回来时位置不变。如果某页滚动挂在 Shell 的公共容器上，要改成页面内滚动。
- **[前端]** 去掉四个业务页的 H1，改为 `.srOnly` 标题。
- 涉及文件：`Shell.tsx/.module.css`、`App.tsx`、`navigation.tsx`、`routes.ts`、`CommandPalette`（删掉「收起侧栏」相关项）、新增 `components/SettingsNav.tsx`、`app/usePageActive.ts`；各页面的 `load` 和全局监听要接入 `usePageActive`。

### 3.1 概览 **[前端]**
- 布局从上到下：草稿提醒 → 四张 KPI → 全宽「出入库趋势」→ 全宽「最近单据」。删掉右栏的库存状态卡和页面顶部的全局日期分段。
- 草稿提醒：数据来自 `documents.list({ status: 'draft' })`，显示「X 张出库草稿待处理」，以及第一张的单号和件数。只有一张时点击直接打开那张单据；多张时跳到单据页并筛选为草稿。
- KPI：出库额、出库毛利、当前库存成本、最短可售天数。出库额、毛利、可售天数固定统计**近 30 天**（C2），卡片上注明口径；库存成本取当前快照，不受下方任何筛选影响。样本不足时显示「—」并写明原因（沿用 `getProductHealth` 的判断）。
- 趋势：自己独立的日期范围「近 7 天 / 近 30 天 / 自定义」，自定义的起止日期必填，且起不晚于止。`TrendChart` 改成双折线（蓝色入库件数、橙棕色出库件数），纵轴单位「件」，30 天时横轴刻度稀疏显示，悬停显示当天两组数字。数据来自 `getDailySeries`：后端只统计已生效单据，加载失败显示错误，不当作 0。删除「明细」视图、导出按钮和「全部商品」筛选（C3）。
- 最近单据：同样式、同选项的独立日期筛选，6 列（编号、类型、日期、渠道、数量、状态），点击行打开真实的单据弹窗。
- 涉及文件：`OverviewPage.tsx/.module.css`、`TrendChart.tsx/.module.css`，新增 `components/ui/RangeFilter`（近 7 天 / 近 30 天 / 自定义，供趋势和最近单据共用）。

### 3.2 商品 **[前端]**
- 列表：去掉 H1；右上保留「新建商品」和「更多」，搜索和「显示已停用」保留。
- 卡片网格：`repeat(auto-fill, minmax(260px, 1fr))`，最多 3 列（容器限宽）。卡片从上到下：1:1 大图（原图，`object-fit: contain`）→ 名称（品牌色）→ 编码 · SKU → 当前库存、平均成本、默认售价 → 预警值（弱化显示）。不显示可售天数。整张卡可点，打开详情。
- 库存告急 / 缺货时，在卡片图片右上角显示徽标（C5），沿用 `StockBadge` 和 `isStockAlert()`；库存正常不显示。预警值的就地编辑移到详情弹窗的「编辑」里。
- 详情弹窗（`ProductDrawerContent`）：主图放大到约 166×166；名称、SKU 和「编辑」放在上部；五项指标为当前库存、平均成本、库存成本、默认进价、默认售价（「可售天数」移出指标区）；期初信息、调整表单（沿用 `AdjustmentForm`，提交时禁用按钮，防止重复提交）、流水（`ProductMovements`：类型、渠道、日期、单号搜索和导出都已具备）保持不变。
- 涉及文件：`ProductsPage.tsx/.module.css`、`ProductDrawerContent.tsx/.module.css`、`ProductImage`（加 `size="lg"`）。

### 3.3 单据 **[前端]**
- 去掉 H1；工具条压成一行：开单菜单、类型、状态、日期（全部日期 / 近 7 天 / 近 30 天 / 自定义）、搜索、总数；空间不够时换行。「更多」菜单里放「导出当前列表 CSV」和「清除筛选条件」。
- 9 列及顺序不变（日期、类型、单号、状态、渠道 · 订单号、数量、金额、毛利、备注）。上一轮在 1100px 以下隐藏备注列，**与「保留 9 列」冲突**，改为窄窗口下表格横向滚动。
- 导出当前列表 CSV：按当前筛选结果在前端生成（带 UTF-8 BOM），保存时复用现有的保存对话框接口。如果现有接口不能保存任意内容，就新增一个只读的 `csv.saveText`。
- 单据弹窗：宽约 960px，最大高度为窗口的 90%，内部滚动。头部是单号、类型、状态、「导出」（只有单据 CSV，不做打印 / PDF，C6）和「作废」（二次确认，原因必填，规则不变）。
- 「金额汇总」按类型区分：
  - 出库：金额、出库成本、毛利。
  - 入库：进价合计、入库总额。
  - 调整：调整数量、成本影响（需要 `documents.get` 返回流水成本；没有的话扩展这个只读查询）。
  - 期初：期初数量、期初成本。
- 附件区块不变（`AttachmentPanel`）。
- 涉及文件：`DocumentsPage.tsx/.module.css`、`DocumentDrawerContent.tsx/.module.css`，可能还有 `services/documents.ts`（只读扩展）、`csv` 的 IPC。

### 3.4 定制（重点）**[前端] + [接口]**，插件不动
- 顶部：三个平级选项卡「生产 / 模板 / 素材库」；右侧为 Photoshop 状态胶囊、「打开 PS」、「任务记录」（`JobsPanel` 弹窗）。去掉 H1 和步骤提示。
- **生产**，从上到下：
  1. 当前模板（选择器 + 文件状态 +「管理模板 →」）。
  2. 替换位置：标题旁有「＋ 添加位置」；卡片网格最多 3 列，自适应变成 2 或 1 列，超过 9 个位置时区域限高并在内部滚动。每张卡显示：第 N 位、位置 ID（`slot_0N`，等宽字体弱化显示）、配置状态、右上角删除（二次确认，文案注明「只删除模板里的这个位置，不改动 PSD」）、狗图和名字图两个小预览、可展开的「图层映射」（狗图层名、名字图层名，失焦或回车保存）。
  3. 导出目录（显示路径 +「更改」→ `pickOutputDir`）和格式（PSD / TIFF）。
  4. 「生成任务」按钮：缺图、图层名不合法、模板文件丢失、**Photoshop 未就绪**（C12，看板 `photoshopPath` 为空）时禁用，并逐条说明原因。点击后经 `createJob` 进入真实队列，状态在「任务记录」里看。
- 点狗图预览只打开**狗图**选择弹窗，点名字图同理。弹窗里能搜索、单选、确认，还能「＋ 导入」（`importAsset(kind)`）；已选的素材可以再换。生产页上**不再放素材库面板**，原来的拖放选图删除。
- 位置的增删改走 `addSlot`、`deleteSlot` 和新增的 `updateSlot`（C8），都写进模板配置，**不碰 PSD 文件**。新位置自动取下一个可用的 `slot_NN`，默认图层名为 `slot_NN_dog` / `slot_NN_name`。
- **模板**：卡片显示名称、PSD 路径（中间省略，悬停看全路径）、文件状态（可用 / 丢失）、位置数；操作有「使用模板」（切到生产页并选中）、「重命名」（C9）、「删除」（确认，注明不删 PSD；有进行中任务时沿用现有的拦截）。「新建模板」改为一步弹窗（约 560px）：名称 + 选择 `.psd` → 创建。后端已经存了绝对路径，生成时复制。创建后提示「去生产页添加位置」。删除 `TemplateWizard` 的三步结构。
- **素材库**：「狗图 / 名字图」二级切换，显示数量、「＋ 导入图片」、素材网格（缩略图、名称、尺寸、是否透明）；每个素材可「抠白底」（沿用 `CutoutReview` 确认流程）和删除（先做 C11 的引用检查）。生成时用的是原图（现有逻辑就是复制原文件）。GIF 等格式以现有导入的限制为准（PNG / JPG）。
- 新增接口（写入模板配置，不改表结构、不改桥接协议）：
  - `psd.updateSlot({ id, dogLayer, nameLayer })`：用 `psdLayerName` 校验，模板内不能重名，有进行中任务时拒绝修改。
  - `psd.renameTemplate({ id, name })`：沿用 `psdTemplateCreateSchema` 里对名称的校验。
  - 两个接口都要补单测（`tests/psdExport.test.ts`）。
- 涉及文件：`PsdPage.tsx/.module.css`、`ProductionView.*`（重写）、`TemplatesView.*`、新增 `AssetLibraryView.*`、`AssetPickerDialog.*`、`SlotCard.*`、`NewTemplateDialog.*`，删除 `TemplateWizard.*`；后端改 `services/psdExport.ts`、`psdIo.ts`、`ipc.ts`、`preload`、`shared/ipc.ts`、`shared/schemas.ts`。

## 5. 风险
1. **页面常驻带来的副作用**（C13）：
   - 隐藏页的键盘监听、轮询、计时器如果没有按激活状态暂停，会和当前页冲突，或者白白消耗资源。
   - 隐藏期间数据变了，回来时如果没有刷新，会显示旧数据。
   - 去掉 `seq` 后，「再点一次同一页就刷新」的习惯改由激活时刷新代替。
   - 应对：统一走 `usePageActive()`，并为「隐藏页不响应 ⌘F / ⌘N」「回到单据页筛选和滚动不变」「在别处改了数据，回来能看到新数据」各写一个 E2E 断言。
2. **C12 行为变更**：Photoshop 没找到时不能再从界面提交任务。如果本机实际装了 PS 但路径检测失败，用户会被挡住，需要在 设置 › Photoshop 连接 里能看到检测结果。
2. **自定义颜色导致对比度不足**：靠对比度计算和警告兜底；状态色不开放自定义。
3. **图层映射无法预先验证**（C10）：只能保证格式合法，PSD 里是否真有该图层，要到 Photoshop 执行任务后才知道。
4. **生产页去掉拖放、改成弹窗选图**：操作步数会多一些，属于按原型取舍。
5. **测试回归**：去掉 H1、改商品卡片、改设置导航后，`flow`、`smoke`、`a11y` 三个 E2E 和截图脚本里的定位方式都要跟着改。
6. **Windows**：标题栏 overlay 与 170px 侧栏的拖拽区需要重新确认；Windows 验收仍放在最后。
7. **端到端出图**：需要你在本机用 Photoshop 实测，自动化环境跑不了。
